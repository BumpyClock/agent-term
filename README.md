Inspired by the agent-deck TUI (https://github.com/asheshgoplani/agent-deck).

Agent Term is a pure Rust app built on GPUI through gpui-kit 0.7.0 from crates.io (Alacritty-backed terminal) for juggling multiple agent sessions across projects in one place.

## Development

```sh
CARGO_BUILD_JOBS=1 cargo run
```
